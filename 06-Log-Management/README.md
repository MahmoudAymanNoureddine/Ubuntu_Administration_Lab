# Log Management Lab

## Overview
This lab demonstrates log monitoring and analysis techniques in Ubuntu Linux using the systemd journal. Log management is an essential skill for Linux administrators, SOC analysts, incident responders, and cybersecurity professionals.

## Objectives
- View system logs
- Review boot logs
- Analyze authentication events
- Identify system errors
- Practice log investigation techniques

## Commands Used
```
 journalctl -n 20
 journalctl -b
 sudo journalctl | grep login
 journalctl -p err
```
