# System Monitoring Lab

## Overview
This lab demonstrates essential system monitoring techniques in Ubuntu Linux. It covers process monitoring, resource utilization analysis, disk usage monitoring, and user activity tracking, which are important tasks for system administrators and SOC analysts.

## Objectives
- Monitor running processes
- Check CPU and memory usage
- Monitor disk usage
- View logged-in users
- Practice system monitoring techniques

## Commands Used
```
 ps aux | head
 top
 df -h
 w
```
