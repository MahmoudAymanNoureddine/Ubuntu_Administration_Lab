# Package Management Lab

## Overview
This lab demonstrates fundamental package management tasks in Ubuntu Linux using the Advanced Package Tool (APT). The lab covers updating package repositories, viewing installed packages, and retrieving package information.

## Objectives
- Update package repositories
- View installed packages
- Display package information
- Practice package management using APT

## Commands Used
```
 sudo apt update
 apt list --installed | grep openssh
 apt show openssh-server
```
